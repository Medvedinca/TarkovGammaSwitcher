# Tarkov Gamma Switcher

**Автоматическая гамма для Escape from Tarkov — светлые ночи в игре и нормальные цвета везде вне её.**

Русский · [English](README.en.md)

</div>

---

Ночные рейды в Escape from Tarkov тёмные, а внутриигровой ползунок яркости помогает лишь отчасти. Многие поднимают гамму в панели управления видеокарты, но тогда при каждом alt-tab весь рабочий стол становится выцветшим.

Tarkov Gamma Switcher живёт в системном трее и меняет гамму экрана **только пока окно Tarkov в фокусе**. Переключились в Discord или браузер — экран сразу становится обычным; вернулись в игру — ваша гамма возвращается.

## Возможности

- **Автопереключение** — гамма применяется, пока активно окно `EscapeFromTarkov`, и сбрасывается, как только фокус уходит.
- **Панель в трее** — левый клик по иконке открывает компактную панель над панелью задач, клик мимо прячет её.
- **Живой предпросмотр** — двигайте ползунки гаммы и контраста (или введите значение) и сразу видите результат на экране, плюс график кривой.
- **Готовые значения** — гамма `2.80`, контраст `1.24`; вернуть их можно в один клик.
- **Несколько мониторов** — можно выбрать, к какому дисплею применять гамму.
- **Запуск вместе с Windows** — по желанию, через автозапуск текущего пользователя (права администратора не нужны).
- **Экстренный сброс** — сброс гаммы на всех мониторах из панели или меню трея.
- **Один экземпляр** — повторный запуск просто открывает уже работающую панель.

## Как пользоваться

1. Запустите `TarkovGammaSwitcher.exe`. Панель откроется возле трея, дальше программа работает из трея.
2. Убедитесь, что **автопереключение** включено (зелёный статус).
3. При желании настройте **гамму** и **контраст** — пока вы двигаете ползунок, экран показывает предпросмотр. Настройки сохраняются при закрытии панели.
4. Запустите Tarkov. Гамма включается, когда игра в фокусе, и выключается при alt-tab.

| Действие | Как |
| --- | --- |
| Открыть / скрыть панель | Левый клик по иконке в трее |
| Меню трея | Правый клик по иконке в трее |
| Точная настройка | Колесо мыши над ползунком (±0.01), с <kbd>Shift</kbd> ±0.1 |
| Закрыть панель | <kbd>Esc</kbd> или клик мимо панели |
| Полностью выйти | **Выйти** в панели или **Выход** в меню трея |

Иконка в трее цветная, когда автопереключение включено, и серая, когда выключено.

## Как это работает

Программа раз в 0,5 с проверяет активное окно. Если в его заголовке есть `EscapeFromTarkov`, она строит гамма-кривую из ваших значений гаммы и контраста и применяет её через функцию Windows GDI [`SetDeviceGammaRamp`](https://learn.microsoft.com/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp). Когда игра теряет фокус, возвращается стандартная линейная кривая. Это тот же системный механизм, который используют панели управления видеокарт и программы вроде f.lux.

Программа **не** читает и не изменяет файлы или память игры, ничего не внедряет и никак не взаимодействует с процессом игры — она смотрит только на заголовок активного окна.

**Файлы и настройки**

- Настройки: `%APPDATA%\TarkovGammaSwitcher\config.json`
- Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `TarkovGammaSwitcher`

## Решение проблем

**После закрытия программы экран остался светлым/тёмным.** Откройте меню трея → **Сбросить экраны** или запустите программу и нажмите **Сброс** в панели. Все мониторы вернутся к гамме 1.00.

**На экране ничего не меняется.**
- «Ночной свет» Windows, HDR и некоторые утилиты цветокоррекции монитора или видеокарты перебивают гамма-кривую — отключите их.
- Windows ограничивает, насколько гамма-кривая может отличаться от стандартной, и молча игнорирует слишком сильные изменения. Если очень большие значения не действуют, попробуйте поменьше.
- Если мониторов несколько, проверьте, что в панели выбран нужный.

**Эффект пропадает в полноэкранном режиме.** Некоторые драйверы сбрасывают гамму в эксклюзивном полноэкранном режиме. Используйте в Tarkov режим *Borderless* (окно без рамки).

## Сборка из исходников

Нужны Windows, Python 3.14 и [uv](https://docs.astral.sh/uv/).

```powershell
git clone https://github.com/Medvedinca/TarkovGammaSwitcher.git
cd TarkovGammaSwitcher
uv sync
uv run main.py                                        # запуск из исходников
uv run pyinstaller --noconfirm TarkovGammaSwitcher.spec   # сборка dist\TarkovGammaSwitcher.exe
```

При пуше тега вида `v1.1.0` GitHub Actions собирает exe и прикрепляет его к релизу.
